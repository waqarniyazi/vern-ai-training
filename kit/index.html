01Install

  1. Open the Terminal app.Open PowerShell.
  2. Paste this and press Enter. 
    curl -fsSL https://claude.ai/install.sh | bash
    irm https://claude.ai/install.ps1 | iex
    npm install -g @openai/codex
    Codex needs Node.js first. Get it from nodejs.org. Install Git for Windows first, from git-scm.com. Claude Code needs it.
  3. Make a folder for today. 
    mkdir ai-workshop
    cd ai-workshop
  4. Start it. 
    claude
    codex
  5. Sign in with your Claude Pro account when it asks.Sign in with your ChatGPT account when it asks.

02Add the plugins

  1. Paste these inside Claude Code, one line at a time.
  2. Close Claude Code and start it again.
  1. Paste these in the terminal, not inside Codex. Choose Codex when it asks which tool. 
    npx skills add mattpocock/skills
    npx skills add pbakaus/impeccable
  2. For ECC, follow the Codex steps at github.com/affaan-m/ECC.
  3. Close Codex and start it again.

03Research: three inputs

  1. Pick a topic.
  2. Plan.
  3. Answer its questions. There will be fewer than five.
  4. Build.
  5. It asks before it acts. Read each request, then allow it.

04Optional: make a video

  1. Set up your computer. It checks Node.js, Git, Python, Remotion, Hairline and Chatterbox, and installs only what is missing. The voice download is about 2 GB.
  2. Plan the video.
  3. Answer its questions.
  4. Build and render.

05Optional tools

    Add thinking-orbs from github.com/RareFormLabs/thinking-orbs to this project.
  2. three.js, for 3D. Nothing to install. It is added when your prompt asks for a 3D scene.
  3. Hermes, to run agents. 
    curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
    iex (irm https://hermes-agent.nousresearch.com/install.ps1)

06DESIGN.md

  1. Go to styles.refero.design and pick a style you like. It is free.
  2. Download its DESIGN.md and put it in your project folder.
  3. Add one line to any prompt. 
    Follow DESIGN.md for colours and type.

07Safe use

  1. Never paste client details, pricing, contracts, passwords or keys.
  2. Open one folder. Never your whole drive.
  3. Read every request before you allow it. Never “allow all”.
  4. In Claude settings, turn off “Help improve Claude”.
  5. Use DeepSeek through OpenRouter, not its own app. In OpenRouter’s privacy settings, block providers that train on your data, and block DeepSeek as a provider.
  6. A person checks everything before it goes outside the company.
